Sauvegardes

Sauvegardez dans le jeu : D → flèche ↓ sur SAVE → Entrée → choisissez la ligne (↑↓) → tapez un nom avec le clavier ABC (ne validez jamais une ligne vide) → Entrée. Pour reprendre : D → LOAD → ligne → Entrée. L'appli enregistre ensuite automatiquement les fichiers de sauvegarde sur l'appareil (toutes les 20 s et quand vous quittez).

Aucune sauvegarde enregistrée.

Installer sur l'écran d'accueil
  1. iPhone / iPad : ouvrir cette page dans Safari → bouton Partager → « Sur l'écran d'accueil ».
  2. Android : Chrome → menu ⋮ → « Installer l'application ».
  3. Ouvrir l'appli depuis l'icône, puis « Importer le jeu » et choisir eternam.jsdos (Fichiers, Drive, Téléchargements…).

Le jeu tourne mieux en mode paysage. Le son démarre au premier appui sur l'écran.

Émulation : js-dos (GPL-2.0, DOSBox) · fflate (MIT).
Les fichiers du jeu ne sont pas inclus dans l'appli : ils restent sur votre appareil.
